# sqmrakdev

APT repository for jailbroken iOS.

    https://sqmrak.github.io/sqmrakdev/

Add that URL as a source in your package manager, or open the page and use the
buttons on it.

## Packages

- **Senko** — full-device VLESS and AmneziaWG client for iOS 5-15, armv7 and
  arm64. <https://github.com/sqmrak/senko>

The repository itself is served from the `gh-pages` branch.
